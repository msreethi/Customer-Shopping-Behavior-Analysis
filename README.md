# Customer Shopping Behavior Analysis

## Project Overview

This project is a Machine Learning classification project developed using Python in Google Colab. The objective is to analyze customer shopping behavior and predict whether a customer prefers **Online Shopping** or **In-Store Shopping** based on customer demographic and shopping-related features.

---

## Problem Statement

Understanding customer shopping preferences helps businesses improve customer experience and make better marketing decisions. This project builds a classification model to predict whether a customer is more likely to shop online or in-store.

---
